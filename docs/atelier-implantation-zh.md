# 连接需求、情境和可行改变

实施涉及实际工作、关系与资源。区分要实施的实践和促进实施的策略，连接障碍、行动、机制与观察。CFIR 组织决定因素，ERIC 命名策略，FRAME 记录调整；它们都不能自动选出最佳本地方案。

## 1. 需求

与相关人员共同工作。

## 2. 策略

说明预期机制。

## 3. 观察

区分实施、服务效果与公平。

## 4. 调整

记录变化及原因。

## 虚构情境 · 工作建议

虚构 CLSC 与社区伙伴希望改善跨部门转介；此教学案例与博士论文方案不同。

### 缺少协调时间

推理过程 : 记录负荷并协商受保护的时间和明确责任。

有用的产出 : 运行协议、资源以及使用、延误和负荷转移记录。

需要注意 : 会议次数不能证明服务得到改善。

### 转介没有反馈

推理过程 : 描绘信息路径，共同制定最小反馈闭环和共享权限。

有用的产出 : 路径图、跟进负责人和反馈指标。

需要注意 : 发出转介不等于获得服务或需求得到满足。

### 获取机会不平等

推理过程 : 识别缺席群体，与面临语言、数字、残障或出行障碍的人设计替代路径。

有用的产出 : 覆盖与退出情况、质性反馈和优先改进行动。

需要注意 : 平均改善可能掩盖差距扩大，须保护隐私。

## 反思问题

- 会议次数不能证明服务得到改善。
- 发出转介不等于获得服务或需求得到满足。
- 平均改善可能掩盖差距扩大，须保护隐私。
