# 让学习过程可见

我的教学目标把知识要求、参与和自主性联系起来。先明确能力，再安排练习并观察推理。无障碍环境支持通过不同途径达到清晰目标。个人准备、同伴讨论和个人修订能够帮助区分参与活动与真正学会。

## 1. 能力

解释、理解或决策。

## 2. 活动

在适当支持下练习。

## 3. 证据

说明选择和替代方案。

## 4. 修订

把反馈用于下一次尝试。

## 虚构情境 · 工作建议

团队根据虚构病例、数据和不同参与者的观点，为基层医疗中的并存社会需求提出应对方案。

### 理解概念

推理过程 : 比较个人与组织层面的解释，界定概念及其局限。

有用的产出 : 附注概念图、个人解释与反例。

需要注意 : 语言流畅不等于理解，应考察新情境中的迁移。

### 解释数据

推理过程 : 选择分母、计算指标，区分关联、因果假设与价值判断。

有用的产出 : 标注步骤的计算、通俗解释和明确局限。

需要注意 : 正确数值也可能来自不适当方法。

### 论证决策

推理过程 : 比较方案、受影响群体、转移的负担与不确定性，再独立修订。

有用的产出 : 包含标准、替代方案和主要反对意见的决策简报。

需要注意 : 区分证据、价值与资源分配上的分歧。

## 反思问题

- 语言流畅不等于理解，应考察新情境中的迁移。
- 正确数值也可能来自不适当方法。
- 区分证据、价值与资源分配上的分歧。
