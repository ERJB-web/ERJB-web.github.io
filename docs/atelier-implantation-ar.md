# ربط الحاجة والسياق والتغيير الممكن

يتعلق التنفيذ بالعمل والعلاقات والموارد. يجب تمييز الممارسة من استراتيجية دعمها وربط العائق بالفعل والآلية والملاحظة. ينظم CFIR المحددات ويسمي ERIC الاستراتيجيات ويوثق FRAME التكييفات؛ لا يختار أي منها تلقائيًا الحل المحلي.

## 1. الحاجة

العمل مع المعنيين.

## 2. الاستراتيجية

توضيح الآلية المتوقعة.

## 3. الملاحظة

التنفيذ وآثار الخدمة والإنصاف.

## 4. التكييف

توثيق التغييرات وأسبابها.

## موقف افتراضي · مقترح للعمل

يسعى CLSC وشركاء مجتمعيون افتراضيون لتحسين الإحالة بين القطاعات. تختلف الحالة عن بروتوكول الأطروحة.

### غياب وقت التنسيق

التفكير : توثيق الأعباء والتفاوض على وقت محمي ومسؤوليات واضحة.

نتاج مفيد : اتفاق تشغيل وموارد ومتابعة الاستخدام والتأخر والأعباء المنقولة.

نقطة انتباه : عدد الاجتماعات لا يثبت تحسن الاستجابة.

### غياب الرد على الإحالة

التفكير : رسم مسار المعلومات والاتفاق على حلقة رد وصلاحيات مشاركة واضحة.

نتاج مفيد : خريطة مسار ومسؤول متابعة ومؤشر رد موثق.

نقطة انتباه : إرسال إحالة لا يثبت الوصول إلى الخدمة.

### تفاوت الوصول

التفكير : تحديد الغائبين وتصميم بدائل مع من يواجهون عوائق لغوية أو رقمية أو متعلقة بالإعاقة.

نتاج مفيد : متابعة الوصول والانقطاع وملاحظات نوعية وإجراء أولوية.

نقطة انتباه : قد يخفي التحسن المتوسط اتساع الفجوات؛ يجب حماية السرية.

## أسئلة للتأمل

- عدد الاجتماعات لا يثبت تحسن الاستجابة.
- إرسال إحالة لا يثبت الوصول إلى الخدمة.
- قد يخفي التحسن المتوسط اتساع الفجوات؛ يجب حماية السرية.
