# البرمجة بالذكاء الاصطناعي مع الاحتفاظ بالحكم العلمي

يمكن لمساعدات الذكاء الاصطناعي التوليدي أن تدعم البرمجة وتطوير الأدوات. أميّز الكود القابل للتنفيذ وصلاحية التحليل وملاءمة سؤال البحث. يجب تحديد السكان والكمية المستهدفة والزمن والبيانات المفقودة. تشمل المسؤولية البشرية السرية والإنصاف وإمكان الاعتراض.

## 1. تأطير

الهدف والبيانات المسموح بها.

## 2. بناء

تغييرات صغيرة ومفهومة.

## 3. تمحيص

الكود والحساب والافتراضات.

## 4. توثيق

المساهمات والقرارات البشرية.

## موقف افتراضي · مقترح للعمل

تحتاج أداة تشرح بحثًا للمديرين والجمهور إلى برمجة وتحليل وتواصل؛ يختلف التفويض باختلاف المهمة.

### تطوير أداة

التفكير : تحديد المدخلات والمخرجات والحالات الحدية ومراجعة التغييرات واستخدام بيانات اصطناعية عند الملاءمة.

نتاج مفيد : مواصفات وسجل نسخ ومثال محسوب مستقلًا.

نقطة انتباه : يجب أن تناسب صلاحيات الوكيل المهمة المصرح بها.

### تحليل وتفسير

التفكير : كتابة السؤال والافتراضات أولًا وطلب بدائل وتمييز التحليل المخطط من الاستكشاف.

نتاج مفيد : سجل للسكان والمتغيرات والكمية المستهدفة والمفقود وتحليلات الحساسية.

نقطة انتباه : قد تُنتج كثرة المخرجات وهمًا بالفهم.

### التعلم مع PAIRR

التفكير : تفكير فردي ثم نقاش الأقران ثم نقد بالذكاء الاصطناعي وتبرير المراجعات.

نتاج مفيد : نسخ متتابعة وتأمل ومهمة نقل دون مساعدة.

نقطة انتباه : جودة المنتج النهائي لا تثبت التعلم؛ يجب توضيح القواعد وإتاحة الوصول.

## أسئلة للتأمل

- يجب أن تناسب صلاحيات الوكيل المهمة المصرح بها.
- قد تُنتج كثرة المخرجات وهمًا بالفهم.
- جودة المنتج النهائي لا تثبت التعلم؛ يجب توضيح القواعد وإتاحة الوصول.
