# Hacer visible el aprendizaje

Mi proyecto docente vincula exigencia intelectual, participación y autonomía. Partir de una capacidad, organizar su práctica y observar el razonamiento. Un entorno accesible permite diferentes vías hacia objetivos claros. La preparación individual, el diálogo entre pares y una explicación revisada permiten examinar lo aprendido.

## 1. Capacidad

Explicar, interpretar o decidir.

## 2. Actividad

Practicar con apoyos adecuados.

## 3. Evidencia

Justificar elecciones y alternativas.

## 4. Revisión

Utilizar la retroalimentación.

## Situación ficticia · propuesta de trabajo

Un equipo organiza una respuesta a necesidades sociales concurrentes en atención primaria a partir de un caso y datos ficticios.

### Comprender

Razonamiento : Comparar explicaciones individuales y organizativas, definir conceptos y sus límites.

Producto útil : Mapa conceptual comentado, explicación individual y contraejemplo.

Punto de atención : Una redacción fluida no demuestra comprensión; pedir transferencia.

### Interpretar datos

Razonamiento : Elegir el denominador, calcular y distinguir asociación, causalidad y valores.

Producto útil : Cálculo anotado, interpretación clara y limitación explícita.

Punto de atención : Un número correcto puede proceder de un método inadecuado.

### Argumentar una decisión

Razonamiento : Comparar opciones, personas afectadas, cargas e incertidumbres; deliberar y revisar.

Producto útil : Nota de decisión con criterios, alternativas y objeción principal.

Punto de atención : Distinguir desacuerdos sobre evidencia, valores y recursos.

## Preguntas para reflexionar

- Una redacción fluida no demuestra comprensión; pedir transferencia.
- Un número correcto puede proceder de un método inadecuado.
- Distinguir desacuerdos sobre evidencia, valores y recursos.
