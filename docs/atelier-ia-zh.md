# 用人工智能编程，保留科学判断

我使用带人工智能辅助的 Positron、Claude 和 Codex 进行编程与工具开发。可运行的代码、统计有效性与研究问题的适切性应分别判断。明确人群、目标估计量、时间顺序及缺失数据假设。人的责任包括保密、公平和质疑结果的权利。

## 1. 界定

目标、获准数据与预期行为。

## 2. 构建

小而可理解的修改。

## 3. 检验

分别检查代码、计算和假设。

## 4. 说明

记录贡献与人的决策。

## 虚构情境 · 工作建议

向管理人员和公众解释研究结果的工具需要代码、分析和传播；不同任务应有不同委托程度。

### 开发工具

推理过程 : 规定输入、输出和边界情况，检查修改并酌情使用合成数据。

有用的产出 : 规范、版本记录和独立计算的参考示例。

需要注意 : 代理的权限应与获准任务一致。

### 分析与解释

推理过程 : 先写问题与假设，要求替代方案，区分预定分析与探索。

有用的产出 : 人群、变量、估计量、缺失数据和敏感性分析日志。

需要注意 : 产出增多可能造成理解的错觉。

### 用 PAIRR 学习

推理过程 : 先个人思考，再与同伴讨论，随后让人工智能提出批评并说明修订理由。

有用的产出 : 连续版本、反思说明和无辅助迁移任务。

需要注意 : 最终成果质量不能单独证明学习；应明确规则和获取机会。

## 反思问题

- 代理的权限应与获准任务一致。
- 产出增多可能造成理解的错觉。
- 最终成果质量不能单独证明学习；应明确规则和获取机会。
